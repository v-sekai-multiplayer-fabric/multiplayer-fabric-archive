# Archive

Decisions that are no longer current — `rejected` (closed) or `superseded` — live
here. They are kept for history.

These records used to sit in the `multiplayer-fabric-manuals` repository, under the
same `_archive/` path, where a leading `_` kept Quarto from rendering them into the
site. The split of 2026-08-07 moved them to this repository. The leading `_` no
longer does any work here, because this repository builds no site. The path stays as
it was so that history and older links keep their shape.

Each file keeps its MADR frontmatter, including the `status` field that records why
it left `decisions/`.
